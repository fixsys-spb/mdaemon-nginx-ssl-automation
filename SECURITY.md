# Security Policy

## Supported Versions
This project is provided as-is. As it deals with SSL certificates and private keys, security is a top priority.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a vulnerability (e.g., accidental exposure of private keys, unsafe file permissions in the Samba share, or command injection in the PowerShell script), please send an email to the repository owner directly or use GitHub's private vulnerability reporting feature.

You should receive a response within 48 hours. If the issue is confirmed, a patch will be released as soon as possible.
